# Meowzix v1.0.1

**Meowzix 1.0.1** brings the changes since the last public v0.8 release together into one Android update.

Download **Meowzix-v1.0.1.apk** for Android 8.0 or later from the assets below. This APK is release-signed; verify its SHA-256 digest against **SHA256SUMS.txt**.

## What's new

- **Telegram music sources:** Select chats, groups, Saved Messages, channels, **and archived chats** as music sources. Archived chats remain in Telegram's Archive; no chat is imported without your selection. Choose Playlist only or Library, and refresh a selected Telegram playlist manually.
- **Telegram proxy links:** Fixed detection and parsing of standard `t.me`, `telegram.me`, and `tg://` MTProto/SOCKS5 proxy links copied or pasted from text, including encoded credentials and multiple links.
- **Playback and controls:** Optional long-press volume-key track navigation, persistent queues, separate Pure Shuffle and adaptive Smart Shuffle, lyrics and sleep timer.
- **Playlists and navigation:** More compact glass-style playlist layouts, contextual queue actions, consistent tab backgrounds, faster cached navigation, and a smoother expandable dock search.
- **Library and offline playback:** Local-device and Telegram tracks remain available through a unified library; selected sources can be refreshed manually. Downloaded music can play offline and background playback continues independently of the Telegram UI.
- **Reliability:** Additional regression tests, Telegram connection recovery improvements, and performance refinements.

## Installation

1. Download **Meowzix-v1.0.1.apk** from this Release.
2. Install it over the previous app version; your local library and preferences should remain in place. Do not uninstall the existing app to update it.
3. Verify the APK with the included **SHA256SUMS.txt** file.

Meowzix integrates with Telegram as a third-party client and is not an official Telegram application. Telegram connection is optional for local audio playback.
