# Meowzix v1.0.0

**Meowzix 1.0** brings local-device and Telegram music together in a polished, offline-capable Android player.

Download **Meowzix-v1.0.0.apk** for Android 8.0 or newer. The release APK is signed, and **SHA256SUMS.txt** is included for download verification.

## Highlights

- **Unified music library:** Browse device audio and music from selected Telegram chats, channels and Saved Messages in one player. Imported Telegram sources remain associated with their playlists.
- **Offline and background playback:** Manage Telegram downloads and offline copies, with Media3 background playback, system media controls and queue persistence.
- **Glass interface:** Refined playlist headers, translucent controls, consistent backgrounds, smoother navigation and a redesigned expandable search dock.
- **Playlist and queue management:** Improved reorder interactions, separate Play Next and Queue lanes, multi-selection with contextual bulk actions, and Telegram forwarding.
- **Manual refresh:** Pull to refresh selected Telegram playlists or rescan local music sources when requested.
- **Listening controls:** Separate Pure Shuffle and adaptive Smart Shuffle, lyrics, sleep timer, player gestures and optional long-press volume-key track skipping.
- **Performance and reliability:** More efficient library navigation, artwork loading, playback recovery, regression tests and database migration coverage.

## Installing and updating

1. Download the APK from the release assets.
2. On Android, allow installation from the app used to open the APK if prompted.
3. To verify the download, compare its SHA-256 digest against **SHA256SUMS.txt**.

Meowzix is a third-party Telegram client integration, not an official Telegram app. Telegram connectivity is optional for playing device-local audio.
