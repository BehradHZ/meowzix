# Meowzix v1.0.2

**Meowzix 1.0.2** focuses on playback reliability and settings fixes.

- **Telegram playback:** Automatically recovers downloaded tracks when TDLib's file identity changes. The app revalidates only the affected track and resumes playback without a playlist refresh.
- **Playback recovery:** Preserves the active queue item and playback position while retrying a stale Telegram source; unrelated tracks are not affected.
- **Settings:** Fixed More-menu drag reordering. Long-press a handle to move neighboring rows, with the new order saved on release.

## Installation

Download **Meowzix-v1.0.2.apk** for Android 8.0 or later. Install it over the existing app to retain your library and preferences. Verify the release APK with the included **SHA256SUMS.txt** file.
